# JS Tactical Board

축구 경기 장면을 보드에 배치하고, 그리고, 메모하고, 장면 사이를 모핑 애니메이션으로 재생해서 PNG 카드·영상·PDF·PowerPoint로 내보내는 개인용 전술 보드 웹앱.

**바로 열기: https://fergie-c.github.io/tactical-notebook/**

설치·로그인 없이 크롬이나 엣지에서 열면 된다. 서버가 없는 정적 사이트라서, 이 폴더를 통째로 내려받아 `index.html`을 더블클릭해도 똑같이 동작한다.

## 구성

| 부분 | 위치 | 하는 일 |
|---|---|---|
| 보드 편집기 | `index.html`, `css/`, `js/` | 선수 배치(H/A + 등번호), 화살표·구역·연결선, 장면 메모, 모핑 재생, 유니폼, 명단 CSV |
| 3D 보기 | `js/view3d.js`, `vendor/three.min.js` | 같은 장면을 2.5D 입체로 보기·녹화 (`3` 키) |
| AI 트래커 | `tracker/` (Python) | 경기 영상 → 선수 위치 → `board.json`. 내 컴퓨터에서만 실행 |

흐름: 영상 → `tracker/` → `board.json` → 보드에서 **불러오기** → 자리마다 등번호 지정 → 수정 → 2D/3D로 내보내기

## 빠른 사용법

1. `H`(홈) 또는 `A`(원정) → 등번호 → `Enter`: 선수가 가운데에 나타난다. 피치를 클릭하면 그 자리로 이동한다.
2. `N`: 새 장면(지금 배치 복사). 선수를 옮기고 `Space`를 누르면 장면 사이가 모핑으로 재생된다.
3. `3`: 3D 보기 전환. 드래그 = 회전, 휠 = 확대, 더블클릭 = 기본 각도. 편집은 2D에서 한다.
4. **내보내기**: PNG 카드, 영상(MP4), 보드만 영상(메모 없이 꽉 찬 화면), **세로 9:16 영상·PNG(릴스·쇼츠, 메모 포함/보드만)**, PDF, PowerPoint, 분석 파일(.json). 3D 보기 중이면 3D 그대로 나간다.
5. `?`: 단축키 전체 목록.

### 명단 CSV

- 팀 하나: `등번호,포지션,이름` (세부포지션·구분·영문명 열이 있으면 같이 읽음). 명단 탭에서 홈/원정을 고르고 불러온다.
- 경기(두 팀 한 파일): 맨 앞에 `팀` 열을 둔다. 예시는 `samples/match_sample.csv`, 양식은 명단 탭의 **경기 양식 받기**.

### 사진으로 명단 (AI)

명단 탭 → **사진으로 명단 (AI)**. 라인업 캡처를 넣으면 Google Gemini가 읽어 경기 CSV 양식으로 만들어 준다. 각자 무료 키를 https://aistudio.google.com/apikey 에서 받아 넣는다(키는 그 브라우저에만 저장). 키가 없으면 창 아래 '명령문 복사'로 다른 AI 채팅을 써도 된다.

### 트래커 결과 불러오기

상단 **불러오기**에서 `board.json`을 고르면 자리(A1, A2…)와 등번호를 잇는 창이 열린다. 시험용 가짜 데이터는 `samples/board_sample.json`. 트래커 사용법은 [`tracker/README.md`](tracker/README.md).

## 꼭 알아둘 것

- **데이터는 지금 쓰는 브라우저에만 자동 저장된다.** 다른 기기로 옮기거나 백업하려면 내보내기 → 분석 파일 저장(.json) → 다른 기기에서 불러오기. 브라우저 기록을 지우면 자동 저장분도 사라진다.
- 영상(MP4)은 크롬·엣지에서 만든다.
- 이 저장소는 공개다. 실제 경기 명단·영상·트래커 결과는 올리지 않는다(`samples/`는 전부 가짜 데이터).
