| 조작 기기 | 노트북 + 마우스 |
| 선수 배치 | 드래그는 불편 → `H`(홈)/`A`(원정) 누르면 중앙에 호출, 바로 등번호 입력 → Enter. 이미 피치에 있으면 그 선수 선택. 선택 후 피치 클릭하면 순간이동 |
| 기본 명단 | 명단에 미리 다 넣어두고 번호로 부름. CSV(`등번호,포지션,이름`)로 일괄 로딩 |
| 애니메이션 | 장면(슬라이드) 사이 **모핑** 방식 |
| 출력 | 장면별 PNG 카드 + 모핑 영상 |
| 언어 | 화면 메뉴 한/영 전환 (메모 내용 자동 번역 아님) |
| 유니폼 | 팀 유니폼·국기에 맞게 무늬 설정 탭 + 색상 선택 탭 |
| 잔디 줄 | 기본 18(UEFA 규격), 숫자로 언제든 변경, **음수 = 색 반전** |

내가(Claude) 해석해서 넣은 부분 — 사용자가 이의 없었지만 명시적으로 확정한 건 아님:
- 화살표 단축키는 `A`가 원정이라 `P`(패스)·`R`(움직임)·`C`(드리블)로 배정
- 클릭 순간이동 후에는 선택이 풀림 (잘못 클릭해 또 옮겨지는 것 방지)
- CSV 불러오기는 지금 선택된 팀 명단을 **통째로 교체**
- 18줄일 때만 UEFA 실제 폭(골라인 쪽 5.5m×4 + 하프라인까지 같은 폭 5줄), 다른 숫자는 균등 분할

### 사용자가 아직 정하지 않은 것 (정하지 말고, 해당 작업에 닿으면 물어볼 것)
1. CSV 세부포지션: 평소 포지션(FotMob) vs '그 경기에서 실제 선 자리' 열 추가 (하면 누가 채울지)
2. 1차 포지션: 구단 등록 포지션 vs FotMob 실제 경기 위치
3. 맨시티 포메이션 4-2-3-1 vs 4-1-4-1 (매체마다 다름, 2026-09-14 맨체스터 더비 명단)
4. 3D 색감·잔디·토큰 광택 최종값 — 사용자가 thetacticsapp 정지 프레임을 줄 예정
5. 영문명(`roster[].en`)을 화면에 쓸지(예: EN 모드에서 이름 대신 표시) — 지금은 보관만

## 3. 현재 기능
- 피치: 전체/왼쪽 절반/오른쪽 절반 보기(`G`), 잔디 줄 개수 설정
- 선수: 홈·원정 호출(`H`/`A`+번호), 클릭 이동, 드래그, 박스 선택, `Shift`+클릭, 라인 선택(`D`/`M`/`F`, `Shift`=원정), 방향키 미세 이동, `Delete`로 피치에서 빼기
- 포메이션: 명단 탭 드롭다운 31종(백4·백3·백5·클래식), 고르면 선발 11명을 **자기 진영 안에** 배치(하프라인 안 넘음), 팀별 마지막 선택 기억. 명단의 포지션(GK/DF/MF/FW) 순서대로 배치. Alt 단축키는 없앰
- 그리기: 패스(실선)·롱킥(`K`, 곡선+그림자)·움직임(점선)·드리블(지그재그)·구역(사각 `Z`/타원 `O`)·텍스트·라인 연결선(`L`)·채운 도형(`S`), 색 5종(노랑/흰/홈색/원정색/검정). 선수 위에서 시작·끝내면 자동으로 붙음
- 장면: `N` 새 장면(배치 복사), 복제, 삭제, 순서 이동, `[` `]` 이동
- 메모: 장면 제목, 경기 시간, 영상 위치, 관찰, 핵심 포인트 / 경기 정보: 분석 제목, 대회, 날짜, 분석가
- 재생: `Space`로 현재 장면부터 모핑 재생, 속도 0.5~2배
- 유니폼 탭: 무늬 13종, 국기 프리셋 12종, 색 슬롯(주/보조/세 번째/번호/골키퍼), 팔레트
- 내보내기: 현재/전체 장면 PNG 카드(1920×1080), 모핑 영상(WebCodecs MP4, 길이·탐색 가능), PDF(표지+장면), PowerPoint(글자 수정 가능), 분석 파일 JSON 저장/불러오기
- 실행취소/다시 실행 150단계, 브라우저 자동 저장, 다크 모드, 좁은 화면 대응
- 3D 보기(`3`): 마네킹 선수, 회전·확대, 각도 버튼, 재생·내보내기에 그대로 반영 / 보드만 영상
- 세로 9:16(릴스·쇼츠): 영상·PNG × 메모 포함/보드만, 2D·3D
- 트래커 `board.json` 불러오기(자리↔등번호 지정) / 경기 CSV(두 팀 한 파일)

## 4. 검증 상태
Claude.ai 작업 환경의 헤드리스 크롬(Playwright)에서 확인 — **사용자 PC(Windows, Galaxy Book)에선 아직 확인 안 됨**:
- 오류 0건으로 확인: 호출·이동·라인 선택·포메이션·그리기·텍스트(한글)·실행취소·재생·PNG·JSON·영상(MP4)·한영 전환·다크·좁은 화면
- CSV: UTF-8(쉼표/세미콜론, 따옴표 포함)과 엑셀 기본 CSV(cp949) 한글 정상, 헤더 건너뛰기, 잘못된/중복 번호 건너뛰기
- 잔디 줄 18 / 12 / -18 / 0 정상, 새로고침 후 유지
- 실제 한글 입력기(IME) 켠 상태의 단축키: 코드상 `e.code`로 대비했지만 실기기 미확인

## 5. 알려진 한계·주의점
- 자동 저장은 브라우저 localStorage라 **그 브라우저에만** 있음. 브라우저 데이터 삭제 시 사라짐 → JSON 백업 습관 필요
- 글꼴은 Google Fonts라 오프라인이면 시스템 글꼴로 대체
- 영상은 크롬·엣지(WebCodecs)에서 MP4로 바로 만들어짐. 그 외 브라우저는 예전 실시간 녹화로 대체되며, 이때는 길이 표시·탐색이 안 될 수 있고 녹화 중 탭을 옮기면 끊김
- 전체 PNG 내보내기 시 크롬이 "여러 파일 다운로드 허용"을 물음
- CSV에서 이름 칸에 포지션처럼 보이는 단어(예: "Keeper")가 있으면 포지션으로 오인할 수 있음 (순서가 바뀐 CSV를 너그럽게 받으려고 넣은 보정 때문)
- 모핑은 직선 보간이라 곡선 경로(돌아 뛰기)는 표현 못 함
